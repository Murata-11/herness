# draw.io 作図手順

次の項目を作図に使う。

- 根拠にした作法IDと誌面ページ
- 図の種類、対象範囲、図で確認したいこと
- 確定済みの要素と関係。状態、イベント、遷移、ガード、動作、担当、順序など、図の種類に応じて必要なもの
- 仮定と未確定事項。仕様上の扱いが決まっている組み合わせと、まだ検討されていない組み合わせを区別する

## 作図と保存

1. [drawio-skill の手順](../../drawio-skill/SKILL.md) を明示的に読み、同じエージェントが図の種類に合う手順を実行する。A-1を適用する場合は、一つの `.drawio` に「状態遷移図」と「状態遷移表」の2ページを作る。状態名・イベント名・遷移条件は共通の定義を使い、状態×イベントの表で網羅性を確認する。図と表の両方に未確定の組み合わせを明示する。図では該当する状態に注記を付け、表では該当するセルを「未確定」とする。仕様上遷移しない組み合わせは「遷移なし」と明記する。
2. 出力先の指定に従う。指定がなければ `docs/diagrams/` に相談内容を表す名前で保存する。新規作成では既存の `.drawio` や対応するPNGと衝突しない名前を使う。既存図の更新依頼では指定された図を編集する。
3. リポジトリのルートから `python3 .agents/skills/drawio-skill/scripts/validate.py <図.drawio> --score` で構造を検証する。スキルの `diagramctl.py doctor` が示す draw.io の絶対パスを使って、`<drawioの絶対パス> --export --format png --page-index 1 --border 16 --output <図.png> <図.drawio>` のように書き出す。複数ページの場合は1から始まるページ番号を指定して1ページずつ出力し、`<図>-01.png`、`<図>-02.png` のように区別する。PNGを開き、日本語ラベルや図形の欠け、重なりを確認する。問題が見つかれば図を修正して再検証・再出力する。

回答に、図で確認できたこと、設計上の未確定事項、根拠の作法IDと誌面ページ、生成したファイルへのリンクを添える。PNG出力に失敗した場合は、検証済みの `.drawio` と失敗したページ・理由を伝える。作図そのものを実行できない場合は、冒頭の項目を作図依頼案として返し、実行を妨げた理由を伝える。
