# C-15 効率を意識してテーブル設計を行う

- 適用場面｜大きなテーブルにデータの重複や不要な結合がある。
- 検索語｜テーブル設計、正規化、主キー、責務分割、重複データ、コピー量
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 164–166、PDF pp. 166–168

## 判断の根拠

意味と責務に沿ってデータを分け、キーで関連付けると、重複、不要なコピー、更新の波及を抑えやすい。

## 確認事項

- 重複する項目を責務ごとに分け、一意なキーで結べるか？
- 必要な読み書きが効率よく行えるか？

## 留意点

分割した関連データを保存・読込みするとき、処理に漏れが生じないようにする。
