# C-8 パラメータチェックに関するルールをプロジェクトで統一する

- 適用場面｜共用部品やAPIで引数チェックの責任を統一する。
- 検索語｜引数チェック、呼び出し側、API契約、事前条件、プロジェクトルール
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 148–149、PDF pp. 150–151

## 判断の根拠

プロジェクトでチェックを行う箇所と責任を定めると、不正入力の見逃しや不要な検査を抑え、呼出し時に何が保証されるか分かりやすくなる。

## 確認事項

- 引数の許容範囲と、誰がチェックしてから渡すかを共有しているか？
- 再利用時もチェック済みの前提を確認できるか？

## 留意点

境界や部品の用途によって保証が異なる場合は、その違いをインターフェースで明示する。
