# C-18 機能変更を行う前にパフォーマンスに与える影響を十分検討する

- 適用場面｜機能や操作手順の変更が、他の処理の応答時間に影響しそうになる。
- 検索語｜機能変更、性能影響、応答時間、性能劣化、操作シーケンス、タイミング
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 171–173、PDF pp. 173–175

## 判断の根拠

機能変更前に処理順序や負荷が変わる箇所を追い、他機能やユーザ操作の応答性への影響を評価する。

## 確認事項

- 処理回数や順序がどう変わり、利用者が待つ区間はどう変わるか？
- 変更による性能低下を測定・見積もりできるか？

## 留意点

変更による便益と性能への影響を把握し、実施するかを判断する。

## 作図の観点

旧案と新案の操作・制御シーケンスを比較し、処理回数と待ち時間が増減する区間を示す。
