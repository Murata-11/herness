# C-5 グローバル変数は極力使用しない

- 適用場面｜グローバル変数を複数箇所が直接更新している。
- 検索語｜グローバル変数、共有変数、スコープ、アクセス関数、データ隠蔽
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 143–144、PDF pp. 145–146

## 判断の根拠

状態を必要な範囲に閉じ込めると、値を誰が変更するか追いやすい。共有が必要ならアクセス経路を制限して変更の影響を把握する。

## 確認事項

- その値をグローバルにする必要があるか？
- 読み書きできる箇所と更新責任を特定できるか？

## 留意点

やむを得ず使う場合は、アクセス関数や命名の方針を決める。
