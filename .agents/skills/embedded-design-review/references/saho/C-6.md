# C-6 不必要な処理はしない

- 適用場面｜形式的な分岐や検査が増え、処理が読みにくくなっている。
- 検索語｜不要処理、冗長分岐、形式的なチェック、到達不能、シンプル
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 145、PDF pp. 147

## 判断の根拠

実際には成立しない分岐や目的のない処理を整理すると、コードの意図と必要な異常処理が分かりやすくなる。

## 確認事項

- 各分岐やチェックを必要とする仕様や入力は存在するか？
- 削減後も必要な検出と復旧が残るか？

## 留意点

前提が崩れる場合まで調べたうえで、不要と判断する。
