# C-12 既存のソフトウェアを改造する前に仕様をよく理解する

- 適用場面｜既存ソフトウェアを改造して新しい装置や用途へ転用する。
- 検索語｜既存仕様、改造、再利用、ブラックボックス、制御タイミング、流用
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 156–158、PDF pp. 158–160

## 判断の根拠

既存の設計や実際の動作を理解してから改造し、変更が他の仕様やタイミングへ及ぼす影響を評価する。

## 確認事項

- 元の装置で成立していた制御順序や時間上の前提を把握したか？
- そのまま流用、改造、作り直しの判断根拠はあるか？

## 留意点

無変更で使える場合を除き、元のコードに手を入れる前に設計レベルでの再利用を検討する。
