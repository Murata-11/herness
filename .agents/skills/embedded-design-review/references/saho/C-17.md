# C-17 モジュールの参照方向を上位から下位へ統一する

- 適用場面｜階層化したモジュールに上位向きの参照が入りそうになる。
- 検索語｜依存方向、上位参照、下位参照、循環依存、レイヤ、モジュール参照
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 168–170、PDF pp. 170–172

## 判断の根拠

参照方向を上位から下位へそろえると、下位が上位の仕様変更に巻き込まれにくくなり、独立した流用や変更が容易になる。

## 確認事項

- 呼出しや参照の矢印が意図した階層方向にそろっているか？
- 上位参照が生成した依存や循環を把握しているか？

## 留意点

例外が必要なら、アーキテクチャを理解するレビュー担当に理由と影響を確認してもらう。

## 作図の観点

層とモジュールの構成図に参照方向を矢印で示し、逆向きや循環の箇所を確認する。
