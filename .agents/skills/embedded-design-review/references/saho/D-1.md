# D-1 多重割込みはどうしても必要な場合のみ使用する

- 適用場面｜割込み処理中に別の割込みを許可するか決める。
- 検索語｜多重割込み、ネスト割込み、ISR、割込み遅延、割込み禁止、RTOS
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 176、PDF pp. 178

## 判断の根拠

多重割込みでは発生順序の組み合わせが増えて設計とテストが難しくなる。応答時間の要件を満たすために必要な箇所へ限定する。

## 確認事項

- ネストを許さないと満たせない割込みの時間要件があるか？
- 許可した場合の順序、共有データ、テストの組み合わせを確認したか？

## 留意点

必要な場合は、リアルタイムOSによる割込み管理を検討する。
