# C-1 ポートスキャンによる外部からの攻撃に備える

- 適用場面｜ネットワーク接続機器で外部に公開する機能を点検する。
- 検索語｜ポートスキャン対策、ネットワーク機器、不要ポート、待受サービス、公開範囲、セキュリティ
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 132、PDF pp. 134

## 判断の根拠

接続を想定していない相手からは待受ポートに到達できないよう、フィルタリングなどで公開範囲を絞る。受信データの異常を検出し、想定外の入力を処理しないことで、システムの不正な動作を防ぐ。

## 確認事項

- 各公開ポートに必要な機能と公開範囲を説明できるか？
- 形式や値が想定と異なるデータを検出し、処理を打ち切れるか？

## 留意点

ネットワークに接続する構成では、想定する利用環境に応じて公開サービスの安全性も検討する。
