# B-4 システム障害時にも稼働を継続するために縮退運転を検討する

- 適用場面｜長期稼働が必要な機器で一部が故障してもサービスを続ける。
- 検索語｜縮退運転、可用性、部分故障、障害隔離、代替機能、冗長化
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 93–94、PDF pp. 95–96

## 判断の根拠

障害を検出して影響を隔離し、代替機能や残った機能で提供できるサービスを設計しておくと、全体停止を避けられる場合がある。

## 確認事項

- 故障箇所の検出・隔離・回復方法を定めたか？
- 障害ごとに、縮退で提供できる機能と停止が必要な機能を明確にしたか？

## 留意点

代替機能のコストと、求められるサービスレベルを設計時に考慮する。
