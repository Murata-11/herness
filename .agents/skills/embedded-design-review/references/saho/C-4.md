# C-4 変数の初期化にあたってはシステムの挙動を網羅的に考慮する

- 適用場面｜初回起動、リセット、異常からの復旧で変数の初期値を決める。
- 検索語｜変数初期化、static、静的変数、自動変数、自動復旧、リセット、値が残る
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 140–142、PDF pp. 142–144

## 判断の根拠

処理系の既定値や以前の処理が残した値に頼らず、利用前に必要な初期値を明示する。特に実行中の復旧処理では、静的変数が以前の値を保持していることがある。

## 確認事項

- 起動・リセット・再初期化それぞれで初期化する値を決めたか？
- 復旧前の値を残す場合、意図した仕様だと説明できるか？

## 留意点

変数の寿命と、システムとして初期化が必要になる時点は一致しない場合がある。
