# B-3 システムの構成に合わせてデータをチェックするメカニズムを用意する

- 適用場面｜外部入力の値や順序を複数の構成要素で検査する。
- 検索語｜データチェック、リミットチェック、バランスチェック、入力順序、許容範囲
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 91–92、PDF pp. 93–94

## 判断の根拠

受付側では値の範囲、処理側では内部データとの整合など、利用できる情報に合わせて検査を割り振ると、無駄を減らし異常状態への進入を防げる。

## 確認事項

- 値域、関連データとの整合、複数入力の順序をどの構成要素が保証するか？
- 同じ保証を重複して確認する箇所や、誰も確認しない箇所がないか？

## 留意点

入力値が単独で範囲内でも、他の入力との組み合わせやその時点のシステム状態で不正になることがある。
