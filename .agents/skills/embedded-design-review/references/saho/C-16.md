# C-16 データアクセスを局所化しデータ更新処理による不整合を防ぐ

- 適用場面｜複数モジュールが同じデータに直接アクセスしている。
- 検索語｜データアクセス局所化、更新API、直接アクセス、データ隠蔽、不整合
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 167、PDF pp. 169

## 判断の根拠

読み書きのルールをAPIへまとめ、直接アクセスする経路を閉じると、更新や検証を一元化して不整合を防ぎやすい。

## 確認事項

- すべての更新・参照が決めたAPIを通るか？
- 整合性の維持に必要な処理がAPI側にあるか？

## 留意点

アクセス用APIを作ったらデータ本体を隠蔽し、抜け道を残さない。
