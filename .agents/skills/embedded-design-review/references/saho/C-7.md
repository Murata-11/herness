# C-7 データ管理機構を使ってデータの一貫性を保証する

- 適用場面｜複数タスクが関連するデータを参照・更新する。
- 検索語｜データ一貫性、共有更新、排他、クリティカルセクション、データ管理
- 出典｜IPA『組込みソフトウェア向け設計ガイド［事例編］』（2012年）、誌面 pp. 146–147、PDF pp. 148–149

## 判断の根拠

データ管理の仕組みで更新をまとめ、参照や更新が不整合な途中状態を扱わないようにする。

## 確認事項

- 関連データをひとまとまりとして更新できるか？
- 同時アクセス時にどの値の組み合わせが見えるか？

## 留意点

排他で時間制約が厳しくなる場合は、保護するデータ単位と排他区間の長さを見直す。
